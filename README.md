# Olimpiadas Desastrosas

Proyecto de Programación: herencia, clases abstractas y polimorfismo en Java.

## Requisitos
- JDK 21
- NetBeans o IntelliJ IDEA con soporte Maven

Abre la carpeta que contiene `pom.xml` como proyecto Maven. Ejecuta `Main.java`.
Desde una terminal con Maven: `mvn compile exec:java`.

El proyecto inicial simula tiro con arco y tiro al plato entre dos países diferentes elegidos al azar. Cada intento se separa del siguiente mediante una pausa de 500 ms.

Las clases fuente se encuentran en `src/main/java`.
